B. INSTAGRAM LIVE REELS & POSTS IMPLEMENTATION OPTIONS

   [OPTION 1: Official Meta Graph API (Automated & Clean Native Grid) - RECOMMENDED]
   • Prerequisites:
     1. Switch Instagram account (@drruchikasubham) to Professional (Creator or Business).
     2. Link Instagram profile to the Facebook Page (drruchikasubham).
     3. Create an app on Meta for Developers (https://developers.facebook.com) 
        and add the "Instagram Graph API" product.
   • Token Management:
     1. Generate a User Token with `instagram_basic` and `pages_show_list` permissions.
     2. Exchange short-lived token for a 60-day Long-Lived Token:
        GET https://graph.facebook.com/v18.0/oauth/access_token
            ?grant_type=fb_exchange_token
            &client_id={APP_ID}
            &client_secret={APP_SECRET}
            &fb_exchange_token={SHORT_LIVED_TOKEN}
     3. Setup automated auto-refresh via a lightweight monthly cron or Next.js API route:
        GET https://graph.instagram.com/refresh_access_token
            ?grant_type=ig_refresh_token
            &access_token={LONG_LIVED_TOKEN}
   • Fetching Reels & Posts:
     Endpoint:
     GET https://graph.instagram.com/me/media?fields=id,caption,media_type,media_url,permalink,thumbnail_url,timestamp&access_token={TOKEN}
     - For Reels / Videos: `media_type === "VIDEO"` -> Use `thumbnail_url` for poster image and `permalink` for one-click Instagram open.
     - For Carousel / Images: `media_type === "IMAGE"` or `"CAROUSEL_ALBUM"` -> Use `media_url`.
   • Next.js Implementation Snippet:
     ```ts
     // app/api/instagram/route.ts
     export async function GET() {
       const token = process.env.INSTAGRAM_ACCESS_TOKEN;
       const res = await fetch(
         `https://graph.instagram.com/me/media?fields=id,caption,media_type,media_url,permalink,thumbnail_url,timestamp&access_token=${token}&limit=6`,
         { next: { revalidate: 3600 } } // Cached for 1 hour
       );
       const data = await res.json();
       return Response.json(data.data || []);
     }
     ```
